House Price Prediction & Regression Modeling

 Project Overview
This project builds and evaluates predictive regression models to estimate house prices based on various housing features and real estate metrics.

 Features & Highlights
* *Exploratory Data Analysis:* Examined feature correlations, housing price distributions, and key pricing drivers.
* *Feature Engineering:* Managed missing entries, encoded categorical variables, and scaled numerical features.
* *Regression Modeling:* Implemented and evaluated Linear Regression and Ridge/Lasso models to optimize prediction accuracy.

 Tech Stack
* Python
* Pandas & NumPy
* Scikit-Learn
* Matplotlib & Seaborn
* Google Colab
