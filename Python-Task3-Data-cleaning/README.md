Data Cleaning & Preprocessing Pipeline

Project Overview
This project focuses on building an end-to-end data cleaning pipeline to audit, transform, and prepare raw data for exploratory analysis and predictive modeling.

 Features & Highlights
* *Missing Value Imputation:* Identified structural missingness and applied statistical imputation techniques.
* *Outlier & Duplicate Removal:* Cleaned duplicate records and managed extreme values to preserve data integrity.
* *Feature Formatting:* Standardized data types, string values, and date-time fields for downstream analysis.

 Tech Stack
* Python
* Pandas & NumPy
* Matplotlib & Seaborn
* Google Colab
