Retail Sales Exploratory Data Analysis (EDA)

 Project Overview
This project performs an Exploratory Data Analysis (EDA) on a retail sales dataset to uncover key business insights, customer purchasing patterns, and sales performance trends.

 Features & Highlights
* *Data Cleaning:* Handled missing values, duplicated entries, and data formatting.
* *Descriptive Statistics:* Summarized key metrics including revenue distribution, average transaction value, and top product categories.
* *Visualizations:* Generated time-series trends and correlation heatmaps to highlight overall sales performance.

 Tech Stack
* Python
* Pandas & NumPy
* Matplotlib & Seaborn
* Google Colab
