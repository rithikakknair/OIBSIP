 Customer Segmentation Analysis

 Project Overview
This project applies data analytics and clustering techniques to segment customers based on their purchasing behavior, demographics, and transaction history.

 Features & Highlights
* *Data Preprocessing:* Cleaned dataset, handled missing values, and scaled numerical features.
* *Exploratory Data Analysis:* Evaluated feature distributions, customer spending patterns, and key demographic trends.
* *Customer Clustering:* Grouped customers into distinct segments to identify high-value cohorts and target marketing groups.

 Tech Stack
* Python
* Pandas & NumPy
* Scikit-Learn
* Matplotlib & Seaborn
* Google Colab
