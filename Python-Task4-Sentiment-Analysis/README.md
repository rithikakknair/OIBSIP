Natural Language Processing (NLP) Sentiment Analysis
 Project Overview
This project builds an end-to-end sentiment analysis pipeline using Natural Language Processing (NLP) techniques to classify text into positive, negative, or neutral sentiment categories.

 Features & Highlights
* *Text Preprocessing:* Implemented tokenization, stop-word removal, and text normalization.
* *Feature Extraction:* Used TF-IDF vectorization to represent textual data numerically.
* *Model Evaluation:* Trained classification models (Naive Bayes / Logistic Regression) and analyzed prediction performance.

 Tech Stack
* Python
* Pandas & NumPy
* NLTK & Scikit-Learn
* Matplotlib & Seaborn
* Google Colab
