Credit Card Fraud Detection

Project Overview
This project focuses on building predictive machine learning models to detect fraudulent credit card transactions within a highly imbalanced dataset.

 Features & Highlights
* *Class Imbalance Management:* Applied resampling techniques (SMOTE / Undersampling) to handle extreme class imbalance between fraudulent and legitimate transactions.
* *Exploratory Analysis:* Analyzed transaction distributions, fraud patterns, and key feature correlations.
* *Model Training & Evaluation:* Trained classification models (Logistic Regression / Random Forest) and evaluated performance using Precision, Recall, F1-Score, and ROC-AUC metrics.

 Tech Stack
* Python
* Pandas & NumPy
* Scikit-Learn & Imbalanced-Learn
* Matplotlib & Seaborn
* Google Colab
